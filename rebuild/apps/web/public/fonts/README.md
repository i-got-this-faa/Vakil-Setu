# Bundled fonts

Unmodified font files and their SIL Open Font License notices from https://github.com/google/fonts/tree/main/ofl. Refresh the Noto script families with `bun scripts/sync-fonts.ts` from the workspace root. Font presence is not proof of translation quality or complete shaping/rendering validation.

Public Sans variable (100–900, upright) is bundled as `PublicSans.ttf`, unmodified from https://github.com/google/fonts/tree/main/ofl/publicsans, with `PublicSans-OFL.txt`. It supplies the Latin interface face; Noto families provide script fallbacks. No runtime font service is used.
